# Airport · Android оқу жобасы

Android Studio-да осы README тұрған буманы ашыңыз. Gradle синхрондалып біткенде **Medium Phone → Run ▶** басыңыз. Android SDK Platform 37 және Android Studio JBR қолданылады. Қолданба Android 8.0 (API 26) және кейінгі нұсқаларына орнатылады.

## Үш демо аккаунт

Кіру экранында email мен құпиясөзді өзіңіз енгізіп, **Кіру** басыңыз. Үшеуінің де демо құпиясөзі `Airport123`.

| Рөл | Email | Мүмкіндігі |
| --- | --- | --- |
| Жолаушы · Қарлығаш | `user@airport.test` | Рейс іздеу, орын таңдау, QR-талон, сапар мұрағаты, дайындық тізімі, рейс хабарландырулары және жұлдызбен пікір жіберу |
| Оператор · Бейбарс | `operator@airport.test` | Рейс қосу және өңдеу, бронь коды немесе рейстің жолаушылар тізімі арқылы тіркеу, өтінімге жауап беру |
| Әкімші · Ерасыл | `admin@airport.test` | Аккаунттарды іздеу, сүзу, бұғаттау, қайта ашу, оператор қосу, өтінімдерді, пікірлерді және журналды оқу |

**Жаңа жолаушы · Тіркелу** арқылы қосымша жолаушы аккаунтын құруға болады. Төменгі мәзірдегі **Профиль** бөлімінде аты-жөніңізді өзгертіп, жеке аккаунттың құпиясөзін ауыстыра аласыз. Құпиясөздердің хэштері жеке salt-пен SQLite-ға жазылады.

Кіру мен тіркелудің құпиясөз есептеулері фондық ағынмен орындалады. Күту кезінде батырмада **Күтіңіз…** көрсетіледі. Экран бұрылғанда тіркелу нысаны мен басталған операция жалғасады. Қате дерек енгізілсе, басқару элементтері қайта қосылады.

## Қорғауда көрсету

1. **Жолаушы → Кіру → Хабарлар → Жаңа өтінім** арқылы сұрақ жіберіңіз.
2. **Профиль → Шығу** басып, оператор болып кіріңіз. «Хабарлар» батырмасында жаңа хабар саны көрінеді. Өтінімді ашып жауап жазыңыз. Қажет болса мәртебесін «Қаралып жатыр» деп өзгертіңіз.
3. Жолаушыға қайта кіріңіз. Жауап сол өтінімде шығады және оқығаннан кейін жаңа хабар белгісі жоғалады. Хабарлар бір Android құрылғысындағы SQLite базасында сақталады. Қорғауда сол эмуляторда аккаунттарды ауыстырыңыз.
4. **Рейс іздеу → Күнді таңдау** арқылы алдағы рейсті табыңыз. Рейс мәліметінен оны сақтауға немесе **Орын таңдау → Броньдау** арқылы QR-талон жасауға болады. Талоннан **Ұшуға дайындық** тізімін ашып, орындалған қадамдарды белгілеңіз. Өткен және тоқтатылған рейстер **Сапарлар** бөлімінің жеке бетінде көрінеді.
5. Әкімші **Аккаунттарды басқару** бөлімінде аккаунт күйін өзгертеді. **Қазіргі ауа райы** Open-Meteo дерегін интернеттен алады. **Google Maps** әуежай бағытын Maps қолданбасында немесе браузерде, **Ресми онлайн-табло** әуежай сайтында ашады.
6. Оператор жолаушыларды бронь кодымен немесе рейстің **Жолаушылар** тізімінен тіркей алады. Рейстің қақпасын немесе уақытын өзгертсе, жолаушы басты беттегі қоңыраудан жаңа мәліметті ашады. Хабарлар бір құрылғының SQLite базасына жазылады.
7. Жолаушы **Пікірлер → Пікір қалдыру** бөлімінде 1–5 жұлдызды таңдап, мәтін жазады. Әкімші сол **Пікірлер** бөлімінен барлық пікірді, орташа бағаны және бағалардың санын көреді. Пікірдің ұзындығы — 1–2000 таңба. Әр жіберу жеке жазба болып сақталады.
8. **Бейнемедиа** бөлімінде берілген екі видео қосымша ішінен ашылады. **Ойнату**, **Кідірту**, **Тоқтату** батырмалары мен MediaController бар. Глобус Canvas анимациясы арқылы қозғалады. Видео файлдары APK ішінде сақталады.

## Саяхат паспортым

**Профиль → Саяхат паспортым** жолаушының расталған сапар санын, қала мөрлерін және барған елдерінің санын көрсетеді. Қала мөрін басқанда сол қалаға барған сапарлардың күні, рейс нөмірі, бронь коды мен орны ашылады. Бір қалаға қайталап барсаңыз, жеке мөрдің астындағы сапар саны өседі. Белгісіз қаланың елі ойдан қосылмайды.

Мөр автоматты түрде ұшу уақыты өткенінен берілмейді. Оператор **Рейстер → рейс → Жолаушылар** ішінен тіркелген жолаушыны таңдап, **Сапарды аяқтау** батырмасын басып, сапардың аяқталғанын растайды. Бұл әрекет тек ұшу уақыты өткен, тоқтатылмаған ұшып шығу рейсіне қолжетімді. Болашақ рейс пен тіркелмеген жолаушыға мөр қосылмайды. Бір сапарды қайта растау қайталама мөр жасамайды.

`travel_stamps` SQLite кестесіне сол кездегі қала, рейс, күн, орын және бронь коды сақталады. Кейін рейс кестесі өзгерсе де, расталған сапар тарихы сақталады. `passportCities()` ішіндегі `GROUP BY city` және `COUNT(*)` қала бойынша сапар санын есептейді. Әр жолаушы өз жазбаларын ғана көреді. Жаңа аккаунтта шынайы сапар расталғанға дейін түсіндірмесі бар бос бет шығады.

Safari веб-нұсқасы компьютердегі `Airport-Web/data/airport.sqlite3` базасын пайдаланады. Осы Java нұсқасының деректері Android құрылғысындағы `airport_course.db` базасында сақталады. Қорғауда әр нұсқаның рөлдерін өз ішінде ауыстырып көрсетіңіз.

## Лекциялармен байланысы

| Тақырып | Жобадағы орны |
| --- | --- |
| Дәріс 1–2. Android платформасы және әзірлеу құралдары | Android Studio жобасы, Gradle, APK |
| Дәріс 3. Layout және Activity | `res/layout/activity_*.xml`, `LinearLayout`, `FrameLayout`, `onCreate`, `onResume`, `findViewById` |
| Дәріс 5. UI элементтері | TextView, EditText, Button, Toast, DatePickerDialog, TimePickerDialog |
| Дәріс 6. Адаптерлер және тізімдер | ListView, ArrayAdapter, Spinner және `row_card.xml` |
| Дәріс 7. Мәзір | `res/menu/home_menu.xml`, PopupMenu |
| Дәріс 8. Manifest, Intent | `AndroidManifest.xml`, экран ауыстыру, Intent extras және `ACTION_VIEW` |
| Дәріс 9. Диалогтар мен фрагменттер | AlertDialog, `ReviewDialogFragment`, `dialog_review.xml`, күйді Bundle арқылы сақтау |
| Дәріс 10–11. SQLite | `SQLiteOpenHelper`, Cursor, ContentValues, WHERE, ORDER BY, GROUP BY, COUNT, insert, query, update және delete |
| Дәріс 12. Мультимедиа мен анимация | `MediaActivity`, VideoView, MediaController, `res/raw`, `TravelSkyView`, `res/anim/banner_enter.xml` |

- **Java** — `app/src/main/java/kz/edu/airportcourse/`. Экрандар `ui/` ішінде, SQLite логикасы `data/AirportDb.java` ішінде.
- **XML** — `app/src/main/res/layout/`. Әр Activity-дің жеке XML-і бар.
- **Сурет пен фондар** — `app/src/main/res/drawable/` және `drawable-nodpi/`. Жаңа мұқаба — ImageGen жасаған `airport_sunrise.png`.
- **SQLite** — `airport_course.db`, схема нұсқасы 6. Android Studio-дағы **App Inspection → Database Inspector** арқылы `users`, `flights`, `bookings`, `saved_flights`, `notices`, `tickets`, `messages`, `reads`, `demo_days`, `ops_log`, `reviews` және `travel_stamps` кестелерін көруге болады. Демо кесте рейстер бетін ашқанда алты күнге толықтырылады. Бұрынғы нұсқадан жаңартқанда бар аккаунт, броньдар және пікірлер сақталады.

Терминалдан жинау командасы — `gradlew.bat :app:assembleDebug`. APK `app/build/outputs/apk/debug/app-debug.apk` жолында шығады.

## Тексеру нәтижесі

«Саяхат паспортым» қосылғаннан кейін бөлек QA пакетінде 39 Android SQLite тексерісі өтті: v5→v6 көшіруі, бұрынғы деректер, рөлдер, жеке паспорт, аяқталмаған сапарларды қабылдамау, қайталанған растау және сапар көшірмесінің сақталуы. Эмуляторда профильден ашу, қала мөрін таңдау, экран бұрылғанда қаланы сақтау және оператор растаған сапардың жолаушыға шығуы тексерілді. Соңғы Android lint нәтижесі — 0 қате, 0 ескерту.

21.11.2026 күні бөлек сынақ орнатылымында Android SQLite пен рөлдерге арналған 88 тексеріс, экрандық сценарийлерге арналған 47 тексеріс және кіру, тіркелу, экран бұруға арналған 28 тексеріс өтті. Екі жергілікті видеода кадрлардың ойналуы, кідірту, жалғастыру және тоқтату тексерілді. Негізгі APK қалыпты `kz.edu.airportcourse` пакет атымен қайта жиналды. 89 lint ескертуі түзетілгеннен кейінгі нәтиже — 0 қате, 0 ескерту. `compileSdk` және `targetSdk` — 37, `minSdk` — 26.

Ескі және жаңартылған APK-ның 14 экранын бірдей SQLite жазбаларымен салыстырғанда көрінетін элементтердің өлшемдері, мәтіндері және басқару күйлері сәйкес келді. Жоғарғы тақырыптардың 8 аймағы пиксель бойынша да сәйкес келді. Қолданылатын суреттер мен екі видеоның мазмұны сақталды. Фоннан тез қайтқанда видеоны жалғастыру жағдайы түзетіліп, қолмен кідірту және экран бұру бөлек тексерілді.
